## Overview

gpt-oss-120b is an open-weight reasoning language model released by OpenAI on August 5, 2025, alongside the smaller gpt-oss-20b, both distributed under the Apache 2.0 license ([OpenAI, "Introducing gpt-oss"](https://openai.com/index/introducing-gpt-oss/)). The Hugging Face model card confirms the Apache 2.0 license and lists the model at 117B total parameters with 5.1B active parameters ([Hugging Face: openai/gpt-oss-120b](https://huggingface.co/openai/gpt-oss-120b)). OpenAI's accompanying model card describes both models as open-weight reasoning models trained with large-scale distillation and reinforcement learning, and states that weights, inference implementations, tool environments, and tokenizers are all released under Apache 2.0 ([arXiv:2508.10925 abstract](https://arxiv.org/abs/2508.10925)).

Positioning: OpenAI reports that gpt-oss-120b reaches near-parity with OpenAI o4-mini on core reasoning benchmarks, outperforms o3-mini and matches or exceeds o4-mini on Codeforces competition coding, MMLU, HLE, and TauBench tool calling, and beats o4-mini on AIME 2024/2025 competition mathematics and HealthBench ([OpenAI, "Introducing gpt-oss"](https://openai.com/index/introducing-gpt-oss/)). The models are optimized for deep research browsing, Python tool use, and developer-provided functions, and use a rendered chat format designed for clear instruction following and role delineation ([arXiv:2508.10925 abstract](https://arxiv.org/abs/2508.10925)).

Notable techniques: the model is an autoregressive mixture-of-experts transformer that alternates banded-window and fully dense attention, uses Grouped Query Attention with learned attention-sink biases in the softmax denominator, RoPE positional embeddings with YaRN context extension, and gated SwiGLU MoE activations ([OpenAI gpt-oss model card PDF](https://cdn.openai.com/pdf/419b6906-9da6-406c-a19d-1bb078ac7637/oai_gpt-oss_model_card.pdf)). Its MoE weights — more than 90% of all parameters — are natively quantized to MXFP4 at 4.25 bits per parameter, which lets the 120b model fit on a single 80 GB GPU such as an NVIDIA H100 or AMD MI300X ([OpenAI gpt-oss model card PDF](https://cdn.openai.com/pdf/419b6906-9da6-406c-a19d-1bb078ac7637/oai_gpt-oss_model_card.pdf); [Hugging Face model card](https://huggingface.co/openai/gpt-oss-120b)).

## Architecture

- Model type: autoregressive Mixture-of-Experts transformer; HF architecture class `GptOssForCausalLM`, model type `gpt_oss` ([model card PDF](https://cdn.openai.com/pdf/419b6906-9da6-406c-a19d-1bb078ac7637/oai_gpt-oss_model_card.pdf); [config.json](https://huggingface.co/openai/gpt-oss-120b/raw/main/config.json))
- Total parameters: 116.83B (≈117B as listed on the HF card) ([model card PDF](https://cdn.openai.com/pdf/419b6906-9da6-406c-a19d-1bb078ac7637/oai_gpt-oss_model_card.pdf); [Hugging Face](https://huggingface.co/openai/gpt-oss-120b))
- Active parameters per token: 5.13B (≈5.1B) ([model card PDF](https://cdn.openai.com/pdf/419b6906-9da6-406c-a19d-1bb078ac7637/oai_gpt-oss_model_card.pdf); [Hugging Face](https://huggingface.co/openai/gpt-oss-120b))
- Parameter breakdown: MLP 114.71B, attention 0.96B, embed + unembed 1.16B; checkpoint size 60.8 GiB ([model card PDF](https://cdn.openai.com/pdf/419b6906-9da6-406c-a19d-1bb078ac7637/oai_gpt-oss_model_card.pdf))
- Layers: 36 (`num_hidden_layers: 36`) ([OpenAI blog](https://openai.com/index/introducing-gpt-oss/); [config.json](https://huggingface.co/openai/gpt-oss-120b/raw/main/config.json))
- Residual stream / hidden size: 2,880 ([model card PDF](https://cdn.openai.com/pdf/419b6906-9da6-406c-a19d-1bb078ac7637/oai_gpt-oss_model_card.pdf); [config.json](https://huggingface.co/openai/gpt-oss-120b/raw/main/config.json))
- Experts: 128 MoE experts per block, top-4 selected per token (softmax-weighted over selected experts via a linear router); `num_local_experts: 128`, `num_experts_per_tok: 4` ([model card PDF](https://cdn.openai.com/pdf/419b6906-9da6-406c-a19d-1bb078ac7637/oai_gpt-oss_model_card.pdf); [config.json](https://huggingface.co/openai/gpt-oss-120b/raw/main/config.json))
- MoE activation: gated SwiGLU (SwiGLU limit 7.0 in config) ([model card PDF](https://cdn.openai.com/pdf/419b6906-9da6-406c-a19d-1bb078ac7637/oai_gpt-oss_model_card.pdf); [config.json](https://huggingface.co/openai/gpt-oss-120b/raw/main/config.json))
- Attention pattern: alternates banded-window (sliding) and fully dense attention; config lists a strict `sliding_attention` / `full_attention` alternation across all 36 layers ([model card PDF](https://cdn.openai.com/pdf/419b6906-9da6-406c-a19d-1bb078ac7637/oai_gpt-oss_model_card.pdf); [config.json](https://huggingface.co/openai/gpt-oss-120b/raw/main/config.json))
- Sliding-window bandwidth: 128 tokens ([model card PDF](https://cdn.openai.com/pdf/419b6906-9da6-406c-a19d-1bb078ac7637/oai_gpt-oss_model_card.pdf); [config.json](https://huggingface.co/openai/gpt-oss-120b/raw/main/config.json))
- Attention heads: 64 query heads per layer, head dim 64, 8 key-value heads — Grouped Query Attention (group size 8) ([model card PDF](https://cdn.openai.com/pdf/419b6906-9da6-406c-a19d-1bb078ac7637/oai_gpt-oss_model_card.pdf); [config.json](https://huggingface.co/openai/gpt-oss-120b/raw/main/config.json); [OpenAI blog](https://openai.com/index/introducing-gpt-oss/))
- Attention sinks: each attention head has a learned bias in the softmax denominator (off-by-one attention), letting heads attend to nothing ([model card PDF](https://cdn.openai.com/pdf/419b6906-9da6-406c-a19d-1bb078ac7637/oai_gpt-oss_model_card.pdf))
- Positional embeddings: RoPE with YaRN scaling (`rope_theta: 150000`, scaling factor 32.0, original max positions 4096) ([model card PDF](https://cdn.openai.com/pdf/419b6906-9da6-406c-a19d-1bb078ac7637/oai_gpt-oss_model_card.pdf); [config.json](https://huggingface.co/openai/gpt-oss-120b/raw/main/config.json))
- Context window: 131,072 tokens for dense layers (128k native) ([model card PDF](https://cdn.openai.com/pdf/419b6906-9da6-406c-a19d-1bb078ac7637/oai_gpt-oss_model_card.pdf); [config.json](https://huggingface.co/openai/gpt-oss-120b/raw/main/config.json); [OpenAI blog](https://openai.com/index/introducing-gpt-oss/))
- Vocabulary size: 201,088 ([config.json](https://huggingface.co/openai/gpt-oss-120b/raw/main/config.json))
- Quantization: MXFP4 on MoE weights at 4.25 bits/parameter (>90% of parameters); config `quant_method: mxfp4` with self-attention, router, embeddings and lm_head left unquantized; tensor types BF16 · U8 ([model card PDF](https://cdn.openai.com/pdf/419b6906-9da6-406c-a19d-1bb078ac7637/oai_gpt-oss_model_card.pdf); [config.json](https://huggingface.co/openai/gpt-oss-120b/raw/main/config.json); [Hugging Face](https://huggingface.co/openai/gpt-oss-120b))
- Hardware footprint: runs within 80 GB of memory / a single 80GB GPU ([OpenAI blog](https://openai.com/index/introducing-gpt-oss/); [Hugging Face](https://huggingface.co/openai/gpt-oss-120b))

## Benchmark explanations

- **AIME 2024 / AIME 2025** — American Invitational Mathematics Examination problem sets; measures competition-level mathematical reasoning, scored as accuracy with and without tool access ([OpenAI blog](https://openai.com/index/introducing-gpt-oss/)).
- **GPQA Diamond** — the hardest subset of graduate-level, Google-proof science multiple-choice questions (biology, chemistry, physics); measures expert-level scientific reasoning ([Hugging Face card links the GPQA dataset](https://huggingface.co/openai/gpt-oss-120b)).
- **MMLU** — Massive Multitask Language Understanding: broad multiple-choice knowledge and general problem solving across academic and professional subjects ([OpenAI blog](https://openai.com/index/introducing-gpt-oss/)).
- **Humanity's Last Exam (HLE)** — extremely difficult expert-written questions spanning many disciplines; measures frontier general problem solving ([OpenAI blog](https://openai.com/index/introducing-gpt-oss/)).
- **SWE-bench Verified** — human-validated real GitHub issues; measures whether a model can produce patches that resolve software bugs in actual repositories ([Hugging Face card links the SWE-bench Verified dataset](https://huggingface.co/openai/gpt-oss-120b)).
- **Codeforces (Elo)** — competitive programming rating derived from Codeforces contest problems; measures algorithmic coding skill on a rating scale rather than a percentage ([OpenAI blog](https://openai.com/index/introducing-gpt-oss/)).
- **τ-Bench Retail (Tau-Bench)** — agentic tool-calling evaluation in a retail customer-service environment; measures multi-turn function calling and policy-following ([OpenAI blog describes TauBench as a tool-calling / agentic evaluation suite](https://openai.com/index/introducing-gpt-oss/)).
- **HealthBench / Hard / Consensus** — health-conversation evaluations scoring the quality and safety of medical responses, with a harder subset and a physician-consensus variant ([OpenAI blog](https://openai.com/index/introducing-gpt-oss/)).
