Llama-3.3-70B-Instruct-FP8 is a dense 70B model that fits on a single GPU at FP8, making it one of the most accessible large models to benchmark. Every GPU in our test set can run it without multi-node, so the comparison is straightforward. We benchmarked it across 6 GPUs on [InferenceX](https://inferencex.semianalysis.com); for a larger dense model, see our [gpt-oss-120b benchmarks](/blog/best-gpu-for-gptoss120b-inference). Note: this model has been superseded on InferenceX but we continue to benchmark it for reference.

## Key Findings

- NVIDIA B200 on FP4 with TRT hits **12,981.3 tok/s/GPU**, the fastest config we tested for Llama-3.3-70B.
- B200 on FP4 with vllm reaches 10,852.1 tok/s/GPU, 16% behind TRT but with much lower TTFT (509.2ms vs 18,571.4ms).
- B200 on FP8 with TRT gets 9,420.6 tok/s/GPU, so the FP4 advantage is 38% on the same hardware.
- AMD MI355X on FP4 with vllm delivers 8,748.9 tok/s/GPU, closing the gap with the B200 to just 19% on vllm.

## Which GPU should you pick for Llama-3.3-70B?

B200 on FP4 with TRT if throughput is all you care about: 12,981.3 tok/s/GPU. The TTFT on that config is 18,571.4ms due to the high-concurrency TRT setup, so for interactive use, B200 on FP4 with vllm is better (10,852.1 tok/s/GPU, 509.2ms TTFT). On AMD, MI355X on FP4 with vllm gets 8,748.9 tok/s/GPU with a very reasonable 584.6ms TTFT.

## FP4 vs FP8 on Llama-3.3-70B

On B200, FP4 with TRT (12,981.3 tok/s/GPU) beats FP8 with TRT (9,420.6 tok/s/GPU) by 38%. On MI355X, FP4 with vllm (8,748.9 tok/s/GPU) leads FP8 with vllm (7,708.5 tok/s/GPU) by 13%. The precision gap is larger on NVIDIA hardware. TPOT is similar between precisions on both vendors, so the throughput gain comes from better batching at lower memory usage.

## TRT vs vllm

On B200 at FP4, TRT (12,981.3 tok/s/GPU) beats vllm (10,852.1 tok/s/GPU) by 20%. At FP8, TRT (9,420.6 tok/s/GPU) beats vllm (7,194.4 tok/s/GPU) by 31%. TRT consistently outperforms vllm on NVIDIA hardware, but it comes with much higher TTFT at these configs. On AMD, only vllm is available.

## NVIDIA B200 vs AMD MI355X on Llama-3.3-70B

Comparing both on FP4 with vllm: B200 hits 10,852.1 tok/s/GPU vs MI355X at 8,748.9 tok/s/GPU, a 24% gap. TTFT is close (509.2ms vs 584.6ms). TPOT favors B200 at 51.7ms vs 64.5ms. MI355X is competitive on this model, and at FP8 the gap narrows further to 7,194.4 vs 7,708.5 tok/s/GPU (MI355X actually wins on FP8 with vllm).

## Fastest time to first token

NVIDIA H100 on FP8 with vllm at concurrency 64: 466.2ms TTFT. B200 on FP4 with vllm is close at 509.2ms. Both are fast enough for interactive chat. If you need the absolute lowest TTFT and can accept 2,568.0 tok/s/GPU, the H100 is the pick. For a better balance, B200 on FP4 with vllm offers 21x the throughput with only 43ms more TTFT.
