GLM-5 is a large model from Zhipu AI. Coverage is still thin: only 3 GPUs and one framework (sglang) in our data. We benchmarked it on [InferenceX](https://inferencex.semianalysis.com); for a model with broader GPU coverage, see our [DeepSeek-R1-0528 benchmarks](/blog/best-gpu-for-dsr1-inference). Note: InferenceX support for this model is still early; expect more GPUs and frameworks in future updates.

## Key Findings

- NVIDIA B200 on FP8 with sglang hits **1,673.6 tok/s/GPU**, the fastest config for GLM-5.
- NVIDIA B200 on FP4 reaches 1,187.2 tok/s/GPU. Unusually, FP8 beats FP4 on this model.
- NVIDIA H200 on FP8 gets 639.5 tok/s/GPU, 38% of the B200. High TTFT (46,130.9ms) makes it impractical for interactive use.

## Which GPU should you pick for GLM-5?

NVIDIA B200 on FP8 with sglang. It's the only option that breaks 1,000 tok/s/GPU with reasonable TTFT (526.6ms). The H200 works but TTFT is 46 seconds, making it unsuitable for anything interactive. MI355X on FP8 only manages 420.5 tok/s/GPU with high TPOT (162.5ms). With only one framework tested, expect these numbers to improve as more serving software adds support.

## FP8 vs FP4 on GLM-5

Unusual result: FP8 beats FP4 on the B200 by 41% (1,673.6 vs 1,187.2 tok/s/GPU). This likely reflects immature FP4 kernel support for GLM-5 in sglang. FP4 does have better TPOT (58.8ms vs 83.7ms) because it runs at lower concurrency (64 vs 128). Cost is also worse for FP4: $0.46/Mtok vs $0.32/Mtok. Stick with FP8 until FP4 support matures.

## NVIDIA B200 vs NVIDIA H200 on GLM-5

B200 is 2.6x faster (1,673.6 vs 639.5 tok/s/GPU). TTFT is the real differentiator: 526.6ms on B200 vs 46,130.9ms on H200. TPOT is closer: 83.7ms vs 62.9ms. Cost is $0.32/Mtok on B200 vs $0.61/Mtok on H200. The H200 isn't viable for interactive use on this model.

## Fastest time to first token

NVIDIA B200 on FP8 at concurrency 128: 526.6ms TTFT. B200 on FP4 at concurrency 64 is close at 605.6ms. MI355X gets 1,368.1ms. The H200's 46,130.9ms TTFT is an outlier, likely a config issue or memory pressure at this model size.

## Cheapest inference per million tokens

NVIDIA B200 on FP8 at $0.32/Mtok (hyperscaler pricing). H200 is $0.61/Mtok, nearly 2x more expensive. MI355X at $0.98/Mtok is the most expensive option. GLM-5 is an expensive model to serve across the board.
