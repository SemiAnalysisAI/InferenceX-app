NVIDIA H200 on TensorRT-LLM FP8 went from 1,333 to 2,454 tok/s/GPU on DeepSeek-R1-0528, an 84% jump. The gain came from adding Multi-Token Prediction (MTP) support to the TRT configs.

## Before/After

|                        |     Before |      After | Change |
| ---------------------- | ---------: | ---------: | -----: |
| Throughput/GPU (tok/s) |      1,333 |      2,454 |   +84% |
| Median TTFT (ms)       |      3,386 |      8,482 |      - |
| Median TPOT (ms)       |       49.1 |      106.1 |      - |
| Framework              |        trt |        trt |      - |
| Concurrency            |         64 |        256 |      - |
| Date                   | 2025-12-15 | 2026-01-14 |      - |

TTFT and TPOT both increased because the after config runs at 4x the concurrency. The throughput gain is the point: 84% more tokens per second per GPU.

The H200 trt FP8 line sat between 1,310 and 1,340 tok/s/GPU from October through mid-December, then jumped to 2,454 on January 14. SGLang FP8 on the same GPU barely moved over that period (1,250 to 1,336). The newer dynamo-trt FP8 disagg config (first seen January 29) lands at 2,320 tok/s/GPU, slightly below the non-disagg trt result.

## What Changed

[PR #392](https://github.com/InferenceMAX/InferenceMAX/pull/392) added Multi-Token Prediction (MTP) support for single-node TRT configs. The PR added a spec-decoding field to config entries and updated launch scripts to select MTP benchmark scripts. This landed for B200 and H200 FP8 TRT configs simultaneously.

## Competitive Context

Before MTP, the H200's best result was 1,333 tok/s/GPU (trt FP8), putting it below the sglang FP8 ceiling (~1,310). After MTP, trt FP8 at 2,454 tok/s/GPU is the H200's top config on DeepSeek-R1. It's still far behind the B200's best at 13,430 tok/s/GPU, but at $0.16/Mtok, the H200 is cheaper per token than B200's dynamo-sglang FP8 disagg config ($0.13/Mtok) only if you compare FP8-to-FP8 at similar concurrency. For cost-sensitive FP8 deployments where Blackwell isn't available, the H200 is now a viable option.
