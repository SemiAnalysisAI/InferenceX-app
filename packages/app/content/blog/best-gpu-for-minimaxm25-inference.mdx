MiniMax-M2.5 is a model from MiniMax. This is one of the few models where AMD MI355X actually beats NVIDIA B200 on peak throughput, making it an interesting data point for anyone comparing the two vendors. We benchmarked it across 6 GPUs on [InferenceX](https://inferencex.semianalysis.com); for a model where NVIDIA dominates, see our [DeepSeek-R1-0528 benchmarks](/blog/best-gpu-for-dsr1-inference). Note: InferenceX support for this model is still early; expect more GPUs and frameworks in future updates.

## Key Findings

- AMD MI355X on FP8 with vllm hits **10,391.0 tok/s/GPU**, the fastest config for MiniMax-M2.5.
- NVIDIA B200 on FP8 with vllm reaches 9,652.0 tok/s/GPU, 93% of the MI355X. Rare to see AMD ahead.
- AMD MI355X on FP8 with atom gets 8,395.9 tok/s/GPU, a second strong AMD config.
- Cost per token is $0.04/Mtok on MI355X vs $0.06/Mtok on B200. AMD wins on both throughput and cost here.

## Which GPU should you pick for MiniMax-M2.5?

AMD MI355X on FP8 with vllm. It's 8% faster than the B200 and 29% cheaper per token ($0.04 vs $0.06/Mtok). B200 has better TPOT (58.4ms vs 108.3ms) and lower TTFT (436.4ms vs 747.7ms), so it's the better pick for latency-sensitive workloads. For batch throughput and cost, MI355X wins.

## vllm vs atom on MiniMax-M2.5

On AMD MI355X, vllm beats atom by 24% on throughput: 10,391.0 vs 8,395.9 tok/s/GPU. vllm runs at concurrency 256 vs 128 for atom, which partly drives the gap. atom has lower TPOT (67.4ms vs 108.3ms). On NVIDIA hardware, only vllm is available for this model. Pick vllm for throughput, atom if you need lower per-request latency on AMD.

## AMD MI355X vs NVIDIA B200 on MiniMax-M2.5

MI355X wins on throughput (10,391.0 vs 9,652.0 tok/s/GPU), an 8% edge. B200 wins on TPOT (58.4ms vs 108.3ms) and TTFT (436.4ms vs 747.7ms). Cost favors MI355X: $0.04/Mtok vs $0.06/Mtok. For interactive chat where latency matters, B200 is the better pick. For batch inference and cost optimization, MI355X pulls ahead.

## Fastest time to first token

NVIDIA H200 on FP8 with vllm at concurrency 128: 340.4ms TTFT. B200 is close at 436.4ms at concurrency 256. MI355X on FP8 with atom gets 512.2ms at concurrency 128. The H100 has an outlier TTFT of 31,646.2ms, likely due to a config issue. For low-latency first tokens, the H200 is the pick (though throughput is only 3,370.8 tok/s/GPU).

## Cheapest inference per million tokens

AMD MI355X on FP8 with vllm at $0.04/Mtok (hyperscaler pricing). That's 33% cheaper than B200 ($0.06/Mtok) with 8% more throughput. MI355X with atom is $0.05/Mtok. AMD MI325X and MI300X are both $0.09/Mtok. This is one of AMD's strongest showings across all models we've tested.
