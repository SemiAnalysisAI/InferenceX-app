# Pareto frontier scene background

Original AI-generated decorative illustration created for the Pareto frontier
feature. Generated with GPT Image 2.5 Flare. It does not depict benchmark results,
real locations, game screenshots, or licensed franchise characters.

- `sunny-castle.webp`: one continuous sunny storybook castle landscape with hills,
  a stream and butterflies.

The asset is 1238 × 929 pixels. Charts render it once across the full plot at
30% opacity with a cover crop, then clip it to the Pareto frontier region.
Keep it local so the export pipeline can embed the image without external
hosts or cross-origin permissions.
