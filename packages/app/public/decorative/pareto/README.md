# Pareto scene backgrounds

Original AI-generated decorative illustrations created for the Pareto highlight
feature. Generated with GPT Image 2.5 Flare. They do not depict benchmark results,
real locations, game screenshots, or licensed franchise characters.

- `sunny-castle.webp`: one continuous sunny storybook castle landscape with hills,
  a stream and butterflies.
- `spooky-swamp.webp`: one continuous purple/black swamp landscape with gnarled
  trees, mist, a crescent moon and bats.

Both assets are 1238 × 929 pixels. Charts render them once across the full plot at
30% opacity with a cover crop, then clip them to the appropriate Pareto region.
Keep them local so the export pipeline can embed the images without external
hosts or cross-origin permissions.
