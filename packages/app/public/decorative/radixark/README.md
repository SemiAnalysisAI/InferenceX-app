# RadixArk-style theme assets

The design reference is [radixark.ai](https://radixark.ai), inspected on
2026-10-16. No RadixArk logo, photography, or Rive file is included.

`hanken-grotesk-latin.woff2` is the Latin variable Hanken Grotesk face, distributed
under the SIL Open Font License 1.1 in `OFL.txt`. Downloaded from the
[Google Fonts CDN](https://fonts.gstatic.com/s/hankengrotesk/v12/ieVn2YZDLWuGJpnzaiwFXS9tYtpd59A.woff2).
The license comes from the
[Google Fonts repository](https://raw.githubusercontent.com/google/fonts/main/ofl/hankengrotesk/OFL.txt).

The smoke, horizon and lens flare are original CSS, not a copy of the site's
Rive animation. They are decorative and do not encode benchmark data.
