# Ghibli theme assets

Everything in this folder is loaded only when the optional `ghibli` theme is active.

Images are official stills published by Studio Ghibli at ghibli.jp; the studio's notice about them is at [ghibli.jp/info/013344](https://www.ghibli.jp/info/013344/) (2020-09-18).

`sprites/totoro-nod.webp` is the Studio Ghibli logo outline from https://www.ghibli.jp/img/totoro.png, not one of the stills. It is used as a small studio nod in the banner and is easy to remove.

No character was drawn or generated. Every character sprite is a cutout from an official still; the transformation column says how.

All files were downloaded on 2026-11-25.
