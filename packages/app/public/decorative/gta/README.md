# GTA V theme artwork

Rockstar Games artwork used by the opt-in GTA presentation theme. Oren
confirmed on 2026-10-05 that Rockstar gave permission to use GTA V assets
for this change in the [requesting Slack thread](https://semianalysis.enterprise.slack.com/archives/C09PULGMVNG/p1791218106121759).
This records the maintainer's representation, not an independently reviewed
license. Rockstar retains ownership; the repository's code license does not
relicense these images. Do not infer permission for audio or unrelated uses.

The GTA Place's [GTA V artwork gallery](https://thegtaplace.com/gtav/artwork/)
identifies these as officially released artwork.

| Local asset            | Original                                                                            | Transformation                                                   |
| ---------------------- | ----------------------------------------------------------------------------------- | ---------------------------------------------------------------- |
| `trio.webp`            | https://thegtaplace.com/images/gtav/artwork/michael_trevor_franklin_extended.jpg    | 1920 × 1190 WebP, quality 84                                     |
| `trio-mobile.webp`     | Same original                                                                       | Right-aligned 1080 × 1190 crop, resized to 720 × 793, quality 82 |
| `vinewood.webp`        | https://thegtaplace.com/images/gtav/artwork/michael_with_vinewood_sign_extended.jpg | Resized to 1600 pixels wide, WebP quality 84                     |
| `vinewood-mobile.webp` | Same original                                                                       | Resized to 800 pixels wide, WebP quality 82                      |

The images are served locally, without third-party hotlinks or tracking.
Responsive sources keep mobile downloads smaller. They load only when the
GTA theme mounts. Font provenance is in `src/app/fonts/GTA-FONTS.md`. The banner wordmark is
live Pricedown text ("Grand Theft InferenceX"), not the GTA V logo.
