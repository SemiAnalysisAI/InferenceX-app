# GTA V theme artwork

Rockstar Games artwork used by the opt-in GTA presentation theme. Oren
confirmed on 2026-10-05 that Rockstar gave permission to use GTA V assets
for this change in the [requesting Slack thread](https://semianalysis.enterprise.slack.com/archives/C09PULGMVNG/p1791218106121759).
This records the maintainer's representation, not an independently reviewed
license. Rockstar retains ownership; the repository's code license does not
relicense these images. Do not infer permission for audio or unrelated uses.

The GTA Place's [GTA V artwork gallery](https://thegtaplace.com/gtav/artwork/)
identifies these as officially released artwork.

The images are served locally, without third-party hotlinks or tracking.
Responsive sources keep mobile downloads smaller. They load only when the
GTA theme mounts. Font provenance is in `src/app/fonts/GTA-FONTS.md`. The banner wordmark is
live Pricedown text ("Grand Theft InferenceX"), not the GTA V logo.

## Site theme depth pass (2026-11-26)

The first depth pass added no file to this directory. What it added is original
work drawn or synthesized in the browser, in `src/components/gta/` (the IP pass
below then replaced the drawn radar map with a map from the game and put
recordings behind four of the interface cues):

| What                                                     | Where                                     | How it is made                                                                                                          |
| -------------------------------------------------------- | ----------------------------------------- | ----------------------------------------------------------------------------------------------------------------------- |
| Skyline, palm, blimp, Buzzard, radar route and blips     | `gta-decorations.tsx`, `gta-site-hud.tsx` | Original inline SVG paths; not traced from Rockstar artwork                                                             |
| Night freeway, traffic, police units, stars              | `gta-traffic.ts`                          | Drawn on a 2D canvas at run time                                                                                        |
| Chart map icons, freight train, stat-bar segments, frame | `gta-charts.ts`                           | Canvas and SVG drawn at run time over the chart's own markers; original outlines in the manner of the game's map legend |
| Interface sounds (16 cues) and three radio stations      | `gta-audio.ts`                            | Synthesized with the Web Audio API                                                                                      |
| Station logos, cursors, weather, searchlights            | `gta-theme.css`                           | CSS gradients and inline SVG data URIs                                                                                  |

The radio stations ("Radio Los Inference", "Non-Stop-Tok FM", "Blaine County Batch") are original step-sequenced patterns. They do not reproduce any song or station audio from the game; the fourth station, added in the IP pass below, is a recording.

How the files are used:

- Everything is requested from this origin only, by code and CSS that load
  with the GTA theme (`src/components/gta/`). Nothing is hotlinked and no
  request leaves the site at run time.
- Audio is fetched and decoded only after a user gesture, and only while
  interface sound (clips) or the radio (one of the two theme loops) is switched on. If a clip
  cannot be loaded, the synthesized cue plays instead.
- The quoted lines shown with these clips are listed with their sources in
  `QUOTES` in `src/components/gta/gta-strings.ts`.
- The chart map icons (mission marker, safehouse, wanted star, weapon pickup)
  are original outlines drawn at run time, not copies of the game's blip
  sprites.
