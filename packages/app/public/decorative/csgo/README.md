# CS:GO artwork

Valve image assets, included under the permission reported by the requesting
maintainer on 2026-10-02. This note records that representation, not an
independently verified license or permission for audio, video, or other assets.
The repository's code license does not relicense Valve's artwork.

- `dust2.webp`: resized to 1920px wide and WebP-encoded from Valve's
  [Dust II A-site screenshot](https://cdn.akamai.steamstatic.com/apps/csgo/images/dust2/screens/shot21a.jpg),
  linked by the [official Dust II page](https://www.counter-strike.net/dust2/).
- `dust2-mobile.webp`: 640×1000 center crop of the same screenshot.
- `csgo-logo.webp`: lossless WebP conversion of the
  [official CS:GO blog logo](https://blog.counter-strike.net/wp-content/themes/counterstrike_launch/images/cs_logo.png).

Assets are hosted locally and requested only when the CS:GO theme is active.
There are no third-party embeds, audio tracks, or external runtime requests.
