# Frontier meme

Image shown by the optional "Meme" easter egg on the Historical frontier views,
once per playback run, the first time another vendor takes part of the frontier
from NVIDIA. It was made by the SemiAnalysis team for a post on X and supplied
for this feature. It is decorative, not benchmark data, and loads only after a
reader turns the easter egg on.

- `jensen-congrats-happy-for-you-nice.webp`: "Congrats / Happy for you / Nice" reaction.
