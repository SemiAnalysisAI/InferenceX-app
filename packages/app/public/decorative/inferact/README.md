# Inferact-style theme assets

The design reference is [inferact.ai](https://inferact.ai), inspected on
2026-10-16. No Inferact logo, photography, or proprietary font is included.

`instrument-serif-regular.ttf` is Instrument Serif Regular, distributed under
the SIL Open Font License 1.1 in `OFL.txt`. Downloaded from the
[Google Fonts repository](https://raw.githubusercontent.com/google/fonts/main/ofl/instrumentserif/InstrumentSerif-Regular.ttf).
It is an open-license substitute for the reference site's STK Bureau Serif,
not the same typeface.

The blue server-rack collage, grain, yellow tiles and orbit animation are
implemented locally in the optional theme's CSS and JSX.
