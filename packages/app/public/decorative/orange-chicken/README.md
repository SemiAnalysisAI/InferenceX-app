# Orange Chicken: files in this folder

Third-party files the Orange Chicken theme (Panda Express: the dish, the brand, the takeout box and the fortune cookie) loads while it is selected. Nothing here is requested from another site at run time, and nothing loads unless the theme is active. Photos were fetched as renditions (`Special:FilePath/<name>?width=...` or `upload.wikimedia.org` thumbnails), not originals. Everything else (dish sprites, chart markers, the game world, the five pans without a photo, most sound effects) is drawn or synthesised in code.

## Note data, not a file

The music bed plays the folk melody Mo Li Hua (Jasmine Flower). The 91 notes in `orange-chicken-audio.ts` (`MOLIHUA`) were read from the MIDI file `Maturika.mid` and re-quantised to sixteenth notes. No recording is shipped; the notes are played by the theme's own Web Audio plucks.

## Fonts

The font files sit in `packages/app/src/app/fonts/` with the other theme fonts, and load only from the lazy theme stylesheet. Each face's OFL text is stored next to it (`LilitaOne-OFL.txt`, `Baloo2-OFL.txt`, `MaShanZheng-OFL.txt`, `Montserrat-OFL.txt`); `ORANGE-CHICKEN-FONTS.md` lists where each is referenced.
