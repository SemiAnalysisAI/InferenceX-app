# Minecraft theme decorative assets

Every file here is a Mojang Studios (Microsoft) asset or is derived from one. Files load only while the Minecraft theme is selected and are served from this folder; nothing is hotlinked or requested from a third party at runtime.

The game assets in `game/` have their own provenance notes in [`game/README.md`](game/README.md).

chips, advancement toasts, the 404 page and the chart creeper). All are lossless crops of files

## Reused from `game/` by the site skin

The site skin also references these existing files without changing them: `game/button.png`,
`game/button-highlighted.png`, `game/button-disabled.png`, `game/crosshair.png`,
`game/xp-bg.png`, `game/xp-fill.png`, `game/title.png`, `game/panorama-0.jpg`, and the sound
effects `game/sounds/random-fuse.mp3`, `random-explode1-4.mp3`, `random-orb.mp3`,
`random-chestopen.mp3`, `fire-ignite.mp3` and `step-grass1.mp3`. The advancement chime is
synthesized at runtime with Web Audio and has no file.
