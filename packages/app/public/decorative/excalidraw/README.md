# Excalidraw theme artwork

- `gpu-sketch.webp`: 1536x1024 AI-generated whiteboard-style illustration of GPU and
  accelerator hardware (data-center compute trays, OAM modules, triple-fan graphics
  cards, circuit boards and heatsinks), drawn in Excalidraw's hand-drawn look and pastel
  palette. Generated for this repository on 2026-10-22; it contains no logos, wordmarks
  or text, and the hardware is generic rather than a replica of any specific product.
- `gpu-sketch-mobile.webp`: 640x1000 center crop of the same illustration.

Assets are hosted locally and requested only when the Excalidraw theme is active.
