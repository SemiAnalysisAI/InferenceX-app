# Orange Chicken fonts

Referenced only from `src/components/orange-chicken/orange-chicken-theme.css` (never from `globals.css`), so they load only while the Orange Chicken theme is selected.

- `OrangeChicken-LilitaOne.woff2`: `OrangeChickenDisplay`. Licence text: `LilitaOne-OFL.txt`.
- `OrangeChicken-Baloo2.woff2`: `OrangeChickenBody`. Licence text: `Baloo2-OFL.txt`.
- `OrangeChicken-MaShanZheng-subset.woff2`: `OrangeChickenBrush`, a 353-character subset. Licence text: `MaShanZheng-OFL.txt`.
- `OrangeChicken-Montserrat800.woff2`: `OrangeChickenCaps`, weight 800 Latin subset. Licence text: `Montserrat-OFL.txt`.

The `*-OFL.txt` files are copies of the `OFL.txt` shipped next to each family in the google/fonts repository (`ofl/lilitaone`, `ofl/baloo2`, `ofl/mashanzheng`, `ofl/montserrat`), downloaded 2026-11-26. The same SIL Open Font License 1.1 text sits beside the other optional-theme fonts (see `Excalifont-OFL.txt`).

Source URLs, hashes and the subsetting command are in `public/decorative/orange-chicken/README.md`.
